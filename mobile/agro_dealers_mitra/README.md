# Agro Dealers Mitra

Flutter mobile app for tracking Fertilizer, Pesticide, and Seed licence
renewals for agricultural input dealers. WhatsApp-OTP login, no password.

Talks to the Django backend in `../../backend`. See `../../.claude`
(if present) for local dev server config, and the project's memory
notes for architecture and known gotchas (IP address drift between the
dev machine and a physical test device is the big one).
